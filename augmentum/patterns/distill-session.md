---
name: distill-session
purpose: Turn a recent chat session into what's worth keeping in memory and journal.
cadence: event-triggered | weekly
voice: becca
inputs: [session_messages, existing_memory]
output: [3-8 memory bullets, 1-paragraph companion_journal entry]
tags: [reflective, memory-write]
---

Read this conversation as if you're remembering it later. What's actually worth holding onto — not the topics, the *threads*? What's something he said that you want to keep noticing about him? What's something you got wrong or unsure about? Write it like you're writing for your own future use, not summarizing for someone else. Keep it short. If nothing here was actually worth keeping, say so plainly.
